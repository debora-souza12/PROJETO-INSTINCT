# PROJETO-INSTINCT

No projeto PROJETO-INSTINCT, crie uma nova aba chamada Nutrição na interface do aplicativo.

Requisitos:

- Adicione apenas a aba “Nutrição” à navegação existente.
- Mantenha o padrão visual, a tipografia e o estilo atual do projeto.
- Não adicione nenhum conteúdo dentro da aba neste momento.
- Não altere as demais abas ou funcionalidades existentes.
- Preserve a integração com o Lovable e a estrutura atual do projeto.
- Faça a alteração diretamente no código existente e salve as mudanças no repositório.

Objetivo: apenas criar a aba Nutrição, deixando seu conteúdo para uma implementação futura.
